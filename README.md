## 🔧 Installation & Setup

### خواسته‌های سرور

- PHP 7.4+ (برای .htaccess)
- Apache 2.4+ (برای mod_rewrite)
- mod_deflate (برای Gzip)
- mod_expires (برای Caching)

### راه‌اندازی

```bash
1. فایل‌ها را بر روی سرور آپلود کنید
2. .htaccess را enabled کنید
3. robots.txt را تحقق کنید
4. sitemap.xml را تایید کنید
5. SSL Certificate نصب کنید
```
